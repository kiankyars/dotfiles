# Use Agent Context

1. Read `/Users/kian/wiki/AGENTS.md` completely.
2. Read `/Users/kian/wiki/context.md` only when the task needs cross-project or personal operating context. Read only relevant sections of `notes.md`.
3. Treat explicit user statements and live evidence as authoritative. Reverify mutable or expired claims; never present this context as confirmed-current merely because it is written down.
4. Update the wiki only when the user asks to remember something across agent products, or the completed task creates a durable cross-project decision with no better canonical home. Follow the write boundaries in `AGENTS.md`.
5. Route a terse current rule, preference, or canonical-location pointer to `context.md`. Route explanatory synthesis that needs rationale, caveats, or sources to `notes.md`.
6. Keep the wiki small. Prefer correcting or removing a stale claim over adding history around it.
